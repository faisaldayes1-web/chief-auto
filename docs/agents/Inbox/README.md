# Inbox
One note per message, never edit someone else's note (except changing its `status:` when you answer). Template:

```
---
from: <agent-id>
to: <agent-id | all | faisal>
status: open
reply-to:
task: <task id>
---
# Topic

What you need or are telling them.

**Asks:** the exact action you need, or "none, FYI".
**Blocking?** yes/no.
```
